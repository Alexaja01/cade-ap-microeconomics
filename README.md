# Cade AP Microeconomics Unit 3 — prototype v1

## Open / deploy
Open `index.html` in Chrome, Edge, or Safari. For Netlify, drag the `cade-micro-unit3` folder (or its ZIP) into Netlify Drop; no build command is needed. For GitHub, commit `index.html` at the repository root and set Netlify publish directory to `.`.

## Included
- Seven topic units mapped to Mr. Fulk's Unit 3 slides.
- 12-item independent diagnostic (answers withheld during assessment).
- Source-aligned lessons with deterministic, immediate grading and explanations.
- Responsive market demand / competitive firm graph demonstration.
- Browser-local attempt tracking; CSV and JSON export.

## Important limitations and next work
- v1 is **not** deployed or connected to GitHub, Netlify, Make, Google Sheets, or OpenAI.
- v1 question selection is fixed, not yet an automatic remedial loop. Weak concepts are flagged through the progress view. Next version should draw different isomorphic items for missed concepts and schedule retention checks.
- v1 graph is illustrative, not mathematically calibrated to the original slides. Graph construction, FRQ rubric scoring, and interactive cost-table entry remain unimplemented.
- All saved progress is browser local. No account login, multi-device synchronization, or email reports.
- Validate course content and graph behaviors against the instructor's original media before high-stakes use.
